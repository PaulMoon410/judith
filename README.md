# The Judith Group Invoice & Tracker App

A modern, mobile-friendly web app for tracking invoices, spending, receipts, gas, and all business transactions for The Judith Group (electrical business).

## Features
- Mobile-responsive React frontend
- Node.js/Express backend
- SQLite database for easy export
- Authentication (login/logout)
- CRUD for expenses, receipts, gas, invoices
- Export/reporting for accountants
- Ready for GitHub and Render deployment
